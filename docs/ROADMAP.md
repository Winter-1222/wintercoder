# 霁雪开发路线

目标是一周做出一个能调用工具、会循环执行的简单 Agent Harness。原则是每一步都小、能运行、能手测，不提前建设后续章节。

## 当前进度

- 第 0 章：工程准备，已完成。
- 第 1 章：LLM + Electron 多轮聊天，已完成。
- 第 2 章：工具定义、一次执行、tool_result 回传和界面展示，已完成。
- 第 3 章：Agent Loop、停止条件、取消、并发和 Plan/Do 模式已完成。
- 第 4 章：System Prompt、动态环境提醒和 Prompt Cache 前缀已完成。
- 第 5 章：五层权限防御、三种权限模式和桌面确认已完成。
- 第 6 章：stdio/HTTP、`.env` Key、后台连接重试、可取消调用和 UI 状态已完成；小规模工具直接发送 Schema。
- 第 7 章：已完成；包括大结果落盘、统一消息序列与旧工具正文清理、手动/自动压缩、超长单次重试和连续失败暂停。
- 第 8 章：会话 JSONL、桌面新建/切换/恢复、根目录项目指令、四类独立 Markdown 记忆、生成索引、按需读取与统一权限写入已完成；后台提取和小模型检索暂缓。
- 第 9 章：尚未开始。

写入和命令工具会按权限模式直接执行或显示确认卡片，硬拦截和路径沙箱始终优先。两种 MCP transport 也进入同一个 Registry 和权限链。会话保存、上下文保护和项目记忆已经接通；三层压缩后的极端超限兜底按约定留待后续。

## 一周路线

1. **第 1 天：工程准备**
   建立 Python、Electron、Git 和本地测试环境。
2. **第 2 天：让 AI 开口说话**
   完成 LLM 适配器、多轮历史、流式界面和状态栏。
3. **第 3 天：工具系统**
   先实现最小工具接口、注册中心和一两个文件读取工具。
4. **第 4 天：Agent Loop**
   让模型请求工具、执行工具、把结果送回模型，直到完成或停止。
5. **第 5 天：提示词与权限**
   加入最小 System Prompt、只读/破坏性判断和用户确认。
6. **第 6 天：MCP**
   先接通一个 Server；延迟加载只做够用版本。
7. **第 7 天：上下文管理**
   完成大结果有界化、统一消息序列与旧工具正文清理，以及手动/自动压缩；会话保存和长期记忆留到第 8 章。
